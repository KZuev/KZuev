Excited to share a new project — **DartCount**. It's a scorekeeper for
darts: it tracks the game, you just throw.

Nothing to install — the project
[runs right in the browser](https://kzuev.github.io/DartCount/), and the
source is on [GitHub](https://github.com/KZuev/DartCount).

## What it already does

- Supports several scoring variants
- Configurable before a game starts
- Fully open source — fork it, tweak it

## What's next

I want to add new game modes, polish the interface, and support
multiplayer games.
