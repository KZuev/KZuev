## About the project

**Lampa-Simkl** is a [Lampa](https://github.com/immisterio/Lampa) sync plugin for
[Simkl](https://simkl.com): watch history, statuses, and automatic scrobbling.
Currently in development — the code is already in the repository, but hasn't been
merged into the main branch yet.

## Planned features

- PIN-code sign-in: enter a code at simkl.com/pin from your phone or computer
- Home rows: "Plan to watch," "Currently watching," trending
- A dedicated section for the watchlist and viewing history
- Card badges: watched, planned
- Auto-scrobbling — marks content watched once a threshold is reached (default 90%)
- Quick status changes right from a movie or show page

Follow progress and discuss it on [GitHub](https://github.com/KZuev/Lampa-Simkl).
