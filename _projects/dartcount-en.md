## About the project

**DartCount** is a tool for scoring and tracking results in darts.
It opens in the browser — nothing to install.

## Features

- Supports several scoring variants
- Quick setup before a game
- Fully open source

## What's next

- New game modes
- A better interface
- Multiplayer games
