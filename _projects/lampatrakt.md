## О проекте

**LampaTrakt** — плагин для [Lampa](https://github.com/immisterio/Lampa), синхронизирующий
её с [Trakt.tv](https://trakt.tv): история просмотров, статусы сериалов, до шести аккаунтов
одновременно и совместный просмотр несколькими профилями.

Это форк [оригинального плагина LampaME](https://lampame.github.io/main/trakttv.js) —
я развиваю его дальше.

## Возможности

- До шести аккаунтов Trakt одновременно, с переключателем
- Совместный просмотр: список показывает только то, что есть в вотчлисте у всех выбранных аккаунтов
- Автоматический выбор и запуск лучшего торрента, синхронизация прогресса с TorrServer
- Бейджи на постерах: просмотрено, смотрю сейчас, в вотчлисте, дата цифрового релиза
- История просмотров, статусы сериалов (смотрю / брошено / просмотрено), расписание выхода серий
- Персональные рекомендации и собственные списки

## Как установить

В Lampa: **Настройки → Плагины → Добавить плагин вручную**, вставить адрес файла:

```
https://raw.githubusercontent.com/KZuev/LampaTrakt/main/trakttv.js
```

После перезагрузки Lampa нужно один раз указать Client ID и Secret приложения Trakt.

Исходники и обсуждение — на [GitHub](https://github.com/KZuev/LampaTrakt).
